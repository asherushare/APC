# Design System

All design tokens are defined in `src/app/globals.css` via `@theme inline {}`. Use these tokens in every UI component. Never use arbitrary Tailwind values (e.g., `[#hex]` or `[14px]`) for values that have a token equivalent.

---

## Color Tokens

## Typography Scale

All levels are defined as CSS utility classes. Always use these — never define custom font sizes.

| Class | Font Size | Line Height | Weight | Use Case |
|-------|-----------|-------------|--------|----------|
| `.text-display-lg` | 48px | 56px | 700 | Hero headlines (desktop) |
| `.text-display-mobile` | 32px | 40px | 700 | Hero headlines (mobile) |
| `.text-headline-md` | 24px | 32px | 600 | Section titles |
| `.text-headline-sm` | 20px | 28px | 600 | Card titles, step headers |
| `.text-body-lg` | 18px | 28px | 400 | Lead paragraphs |
| `.text-body-md` | 16px | 24px | 400 | Default body text |
| `.text-body-sm` | (via Tailwind `text-sm`) | — | — | Secondary body text |
| `.text-label-md` | 14px | 20px | 500 | Labels, metadata, chips |
| `.text-label-sm` | 12px | 16px | 600 | Micro-labels, tracking-wider tags |

**Font Family**: Plus Jakarta Sans, loaded via `next/font/google` in `src/app/layout.tsx`. Available as CSS variable `--font-plus-jakarta` and applied globally on `<body>`.

## Custom CSS Utility Classes

These are defined in `src/app/globals.css` and cannot be generated by Tailwind scan alone. They must be used by name.

### Background Patterns

| Class | Effect | When to Use |
|-------|--------|-------------|
| `.saura-pattern` | Repeating Saura tribal star SVG at 3% opacity (green) | Full-page hero backgrounds, section backdrops with cultural texture |
| `.hero-gradient` | Left-solid (#F8FAF9, 95%) → right-transparent (40%) | Overlay on hero images to keep text readable |
| `.glass-card` | Semi-transparent white (`rgba(255,255,255,0.8)`) + `backdrop-filter: blur(8px)` | Cards floating over hero images or backgrounds |

### Elevation & Shadow

| Class | Effect | When to Use |
|-------|--------|-------------|
| `.shadow-tribal` | `0 10px 30px -10px rgba(11,107,58,0.15)` | Default card elevation (subtle green shadow) |
| `.shadow-tribal-hover` | `0 20px 40px -10px rgba(11,107,58,0.2)` | Elevated state on hover |

### Animations

| Class | Keyframe | Duration | When to Use |
|-------|----------|----------|-------------|
| `.animate-fade-in` | `fade-in` — opacity 0→1 + translateY(-6px→0) | 0.18s ease-out | New wizard steps, modal content, section reveals |
| `.animate-mesh` | `mesh-gradient` — background-position shift | 15s ease infinite | Success screen backgrounds |
| `.animate-slide-in-right` | `slide-in-right` — translateX(100%→0) | 0.25s cubic-bezier | Sliding drawer panels (Booking, mobile menu) |
| `animate-[whatsapp-pulse_2s_infinite]` | `whatsapp-pulse` — ring glow | 2s | WhatsApp floating button pulse |
| `animate-pulse` | Tailwind default | 2s | Replace button on uploaded files |
| `animate-[shake_0.4s_ease-in-out]` | `shake` — translateX(±4px) | 0.4s | Invalid form field shake |

### Interactive

| Class | Effect |
|-------|--------|
| `.focus-ring` + `.focus-ring:focus-visible` | Outlines with `--color-tribal-gold` on keyboard focus |

### State

| Selector | Effect |
|----------|--------|
| `body.mobile-menu-open` | `overflow: hidden` — prevents background scroll when mobile nav is open |
| `body.mobile-menu-open .whatsapp-btn-container` | Hidden — prevents WhatsApp button from intercepting menu clicks |

## Layout & Spacing Conventions

| Convention | Value | Applied Via |
|-----------|-------|------------|
| Max content width | 1280px | `<Container>` component |
| Horizontal padding | `px-5` (mobile) / `px-16` (md+) | `<Container>` component |
| Base spacing unit | 4px | Tailwind default — all spacing should be multiples of 4px |
| Section vertical padding | `py-16 md:py-24` | Applied per section |
| Form card max-width | `max-w-2xl` (672px) | Used in wizard, booking forms |

## The `cn()` Utility

Used for conditional Tailwind class composition. Always prefer `cn()` over string interpolation.

```typescript
import { cn } from '@/lib/utils';

// ✅ Correct
<div className={cn(
  'base-class other-class',
  isActive && 'active-class',
  hasError ? 'border-red-500' : 'border-outline-variant'
)} />

// ❌ Avoid
<div className={`base-class ${isActive ? 'active-class' : ''}`} />
```

Tailwind defaults, no custom breakpoints defined.

| Breakpoint | Min-Width | Common Usage |
|-----------|-----------|-------------|
| (default) | 0px | Mobile-first base styles |
| `sm:` | 640px | Small devices |

## Premium Card — Worked Example

A standard card following APC design conventions:

```tsx
<div className={cn(
  // Base
  'bg-surface-container-lowest border border-outline-variant/30 rounded-2xl p-6',
  // Elevation
  'shadow-tribal hover:shadow-tribal-hover',
  // Transition
  'transition-all duration-300',
  // Hover lift
  'hover:-translate-y-1',
  // Conditional
  isActive && 'border-primary/40 bg-primary/5'
)}>
  <h3 className="text-headline-sm font-extrabold text-on-surface">Card Title</h3>
  <p className="text-body-md text-on-surface-variant mt-2">Description text.</p>
</div>
```

## Anti-Patterns

| ❌ Anti-Pattern | ✅ Correct Approach |
|----------------|-------------------|
| `text-[#0B6B3A]` | `text-primary` |
| `bg-[#F8FAF9]` | `bg-surface` |
| `text-[14px]` | `text-label-md` |
| `style={{ color: '#0B6B3A' }}` | `className="text-primary"` |
| Defining new colours in a component | Add a CSS variable to `globals.css` and create a PR |
| Using generic Tailwind green (`text-green-700`) | Use `text-primary` or `text-dark-green` |
